# Pre-release verification checklist

- [x] All S01–S12 folders have a workbook, README and full DATA directory.
- [x] Original PACE Python `.py` scripts are available as individual files.
- [x] Scientific manifests and local checksum verifiers are included.
- [x] A visually formatted overview workbook is provided.
- [x] Manuscript and verbatim reviewer comments are excluded.
- [x] Confirm public GitHub data/code upload and visibility (verified via GitHub API).
- [ ] Review upstream redistribution licenses and rights for third-party sequence libraries.
- [ ] Approve public data/code release with all manuscript authors.
- [ ] Tag a stable GitHub Release after all repository files pass checksum verification.
- [ ] Optionally archive the stable release with Zenodo and include its actual DOI once assigned.
