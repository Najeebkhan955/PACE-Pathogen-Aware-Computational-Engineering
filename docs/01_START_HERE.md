# Getting started with PACE supplementary evidence

1. Begin at [README](../README.md) and open [the visual Excel overview](../PACE_Repository_Overview.xlsx).
2. Navigate one of the [12 supplementary folders](../SUPPLEMENTARY_INDEX.csv).
3. The workbook is a readable **index and summary**; the `DATA/` folder contains **complete unabridged data**.
4. The generated experiment outputs from Phases 1–14C have different roles. Read their group README and distinguish original historical predictions, newly fitted models, and exploratory rescoring.
5. Verify file checksums before reusing a local copy.
