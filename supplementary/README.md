# PACE supplementary research materials | S01–S12

This collection provides the supporting peptide datasets, experimental source observations, model predictions, computational comparisons, sequence-design results and analysis code for the PACE study.

**Contents:** Each S01–S12 collection has a scientific Excel workbook and a research folder containing its full supporting records. Workbooks are designed for navigation and interpretation; CSV, FASTA, figures, and scripts retain the detailed data required for analysis.

## Research interpretation

The deposited experimental MIC/hemolysis source measurements support model development and benchmarking. **The 20 computationally designed PACE peptides have predicted properties only**, so their model-derived MIC, HC₅₀ and selectivity values are distinct from measured source records.

The quantitative comparisons retain their defined cohorts and error assumptions. Source-species pooling, peptide modification, assay heterogeneity and model-dependent scoring are documented with the corresponding data.
